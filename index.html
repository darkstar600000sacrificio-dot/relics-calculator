Public formulas (easy to verify)
Level 1 status = Current status − (Relic level − 1)
Status perfection (%) = Level 1 status ÷ Level 1 maximum × 100
General perfection (%) = Sum of included status percentages ÷ Number of included statuses
Perfection score = General perfection (%) ÷ 10
Real multiplier = (1 + DMG ÷ 100) × (1 + mode bonus ÷ 100)
Level 1 maximums are configured below: DMG 10, Raid 10, Challenge 35, Endless 35. Statuses can use decimal increments of 0.1. DMG is required; the other statuses are optional. Four entered statuses show ??? for general perfection.

Higher-Level Status Simulator

Preview how your current relic's statuses would look at a higher level. Every level gained adds +1 to each existing status.

Simulation—
Final Status BonusesSimulated values
Final MultipliersCombined effects
Simulator formulas
Levels gained = Target level − Current relic level
Simulated status = Current status + Levels gained
Final status bonus = Simulated status value
DMG multiplier = 1 + Simulated DMG ÷ 100
Mode multiplier = (1 + Simulated DMG ÷ 100) × (1 + Simulated mode status ÷ 100)
Combined bonus (%) = (Final multiplier − 1) × 100
Only statuses present on the relic are simulated. A mode multiplier appears only when both DMG and that mode's status are entered. Target level must be equal to or higher than the current level.

For maintainers: edit the PERFECTION_CONFIG object in the JavaScript to change status maximums or rules.
